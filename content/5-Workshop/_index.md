## Deploying Macket on AWS

This workshop builds a small Macket environment in the **Singapore Region**. Start with the network, **Amazon EC2**, and **Amazon RDS**, deploy the web application, then connect Apify, the AI Worker, and private **Amazon S3** media storage. The last stage checks the listing flow from collection to the storefront.

[Macket source code on GitHub](https://github.com/hoanganhdo2316-png/macket-aws)
