### Objective

Prepare the code, configuration, and input for the lab.

### Steps

1. Get the code from the [Macket repository](https://github.com/hoanganhdo2316-png/macket-aws). Use `backend/` for FastAPI, `frontend/` for the web app, `apify/` for collection, and `deploy/` for deployment configuration.
2. Prepare Git, Python 3.12, Node.js, Docker, an authorized AWS environment, a domain, and Apify and OpenAI API accounts.
3. Pick one authorized public source group and one sample post. Set a small limit for the first run and prepare a separate environment configuration for credentials.

### Expected result

The source and one sample listing are ready for the deployment walkthrough.
